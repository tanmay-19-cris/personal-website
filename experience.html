Experience

I'm still learning and experimenting, but these are the projects and skills that I've spent the most time on so far. Every project taught me something new, from game development to web design and teamwork.

2D Platformer Game

I built a 2D platformer game using the Godot Engine. I learned level design, player movement, animations, collision systems, and how to turn random ideas into a playable game. This was my first proper game project and it taught me a lot about problem solving and game mechanics.

Portfolio Website

I created this portfolio website from scratch using HTML, CSS, and JavaScript. I worked on layouts, animations, responsiveness, navigation, and making the whole site feel smooth and personal. This is one of the projects I'm most proud of because it combines everything I've been learning recently.

Minecraft Building

I've spent countless hours designing survival bases, headquarters, and large-scale Minecraft projects. This helped me become more creative, patient, and better at planning bigger ideas before actually building them. Minecraft is still one of my favorite places to experiment with architecture and design.

Football Journey

Football has been one of the biggest parts of my life since 2017. It taught me teamwork, discipline, leadership, and how to keep improving even when things don't go the way I want. I've played for teams, competed in matches, and grown a lot both on and off the field.
